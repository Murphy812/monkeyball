# Формат контента

Весь контент игры лежит в папке `content/`. Код его не содержит: можно менять тексты,
числа и карточки, не трогая программу. При запуске `npm run dev` игра подхватывает
изменения сразу, без перезапуска; ошибки показываются прямо на экране.

| Файл | Что в нём |
| --- | --- |
| `settings.yaml` | Числа баланса: деньги на старте, скорость угрозы, усталость и т.д. Комментарии в файле объясняют каждое |
| `horses.yaml` | Стартовая труппа |
| `biomes.yaml` | Биомы и их множитель скорости |
| `towns.yaml` | Города по порядку маршрута; `distance` — длина перегона до города, `biome` — местность |
| `cards/*.yaml` | Дорожные карточки. Файлов может быть сколько угодно, удобно делить по биому и сезону |

## Карточка

```yaml
- id: frozen_stream            # латиница, цифры, _ ; уникальный
  biomes: [forest]             # где может выпасть
  seasons: [winter]            # по умолчанию winter
  weight: 1                    # относительная частота, по умолчанию 1
  once: true                   # не повторяется за прогон (по умолчанию true)
  scheduledOnly: false         # true = только как отложенное последствие
  requires:                    # необязательно: условия появления
    flags: [angry_forester]    #   все эти флаги стоят
    notFlags: [met_hermit]     #   ни одного из этих
    minMoney: 20               #   денег не меньше
  timer: 6                     # необязательно: секунды на решение
  defaultChoice: 0             # что выбирается по истечении таймера (0 или 1)
  text:
    ru: Ручей замёрз. {horse} нюхает лёд.     # {horse} — имя случайной лошади
    en: The stream is frozen. {horse} sniffs the ice.
  choices:                     # ровно два варианта
    - label: { ru: Переходить по льду, en: Cross the ice }
      effects: { miles: 4 }
      later: { card: limping, after: 2 }      # через 2 шага покажется карточка limping
    - label: { ru: Искать брод, en: Find a ford }
      effects: { miles: -5 }
```

### Эффекты

| Поле | Значение |
| --- | --- |
| `money` | ± деньги |
| `threat` | ± мили отрыва от угрозы (плюс = оторвались) |
| `stamina` | ± стамина всех лошадей |
| `subjectStamina` | ± стамина лошади из `{horse}` |
| `miles` | ± мили по текущему перегону |
| `setFlags` / `clearFlags` | поставить / снять флаги для `requires` |

После каждого выбора караван проезжает шаг: мили зависят от стамины лошадей и биома,
лошади устают и едят, угроза приближается.

## Проверка

`npm run validate` проверяет весь пак: опечатки в полях, ссылки на несуществующие карточки,
флаги, которые ставятся, но нигде не проверяются, и наоборот, пропущенные переводы.
Та же проверка запускается на каждый коммит.

`npm run bot` прогоняет тысячи партий случайными стратегиями и показывает процент выживания —
удобно, чтобы увидеть, как правка чисел меняет сложность.

## Дебаг-панель

Клавиша `` ` `` (или «Дебаг» вверху): состояние прогона, флаги, запланированные карточки,
предпросмотр любой карточки по id, предупреждения валидатора.
