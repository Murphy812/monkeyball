# Монкибол

Прототип пошаговой карточной игры о странствующем цирке: обезьяна-менеджер ведёт труппу
лошадей сквозь зиму, а по пятам идёт Дикая охота.

Веб-версия для плейтестов, позже — мобильная (Capacitor).

## Запуск

```bash
npm install
npm run dev        # игра на http://localhost:5173 с горячей перезагрузкой
npm test           # тесты ядра
npm run validate   # проверка контента
npm run bot        # балансные прогоны ботом
npm run build      # сборка в dist/
```

Плейтест-билд выкладывается на GitHub Pages при каждом пуше в `main`.

## Устройство

- `src/core/` — ядро симуляции: чистые функции `(контент, состояние, действие) → состояние`.
  Прогон = зерно + список действий, из этого строятся сохранения, история и повторы.
- `src/content/`, `content/` — контент-пак в YAML и его загрузка. Формат: [docs/content-format.md](docs/content-format.md).
- `src/ui/` — интерфейс на Preact.
- `src/platform/` — сохранения и всё, что зависит от устройства.
- `tools/` — валидатор контента и бот для баланса.
